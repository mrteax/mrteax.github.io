# 旅行内容架构与隐私改造设计

## 目标

把现有旅行内容整理成稳定、可扩展的三级结构：

1. 旅行首页：按大洲筛选国家。
2. 国家首页：汇总该国家的旅行内容。
3. 内容页面：签证准备、行前规划、行程安排各自独立。

同时移除公开内容中能够推断实际同行人员构成的信息，但保留无障碍、体力、儿童票等有实用价值的通用提示。

## 信息架构

### `travel.html`：旅行首页

- 顶部保留旅行主题标题，不显示具体出行人数或同行关系。
- 增加大洲筛选 Tag：
  - 全部
  - 欧洲
  - 亚洲
  - 北美洲
  - 南美洲
  - 非洲
  - 大洋洲
- 当前只有法国国家卡片，归类为欧洲。
- 国家卡片显示国旗、国家名、内容数量和路线摘要。
- 点击法国进入 `france.html`。
- 筛选为空时显示明确的空状态。
- 结构支持未来通过添加国家卡片和 `data-continent` 属性扩展，不引入数据框架。

### `france.html`：法国国家首页

- 显示法国标题、旅行日期和路线摘要，但不显示人数、年龄或家庭关系。
- 放置三个同级入口：
  1. 签证准备
  2. 行前规划
  3. 行程安排
- 卡片分别说明内容范围，避免用户进入后再寻找。
- 可保留出发倒计时，但文案只写“距出发还有 N 天”，不写出发人或同行信息。

### `france-visa-2026.html`：签证准备

- 由现有 `france-schengen-2026.html` 迁移并重命名。
- 保留签证类型、材料清单、预订策略、英文模板、递签当天排序。
- 身份清单使用匿名角色：
  - 在职申请人
  - 未成年申请人
  - 退休申请人
  - 共享材料
- 删除或泛化具体家庭结构：
  - “父亲/母亲/父母/孩子”改为“费用担保人/监护人/未成年申请人/退休申请人”。
  - 英文模板中的家庭成员列表改为可复用占位符。
  - 删除能推断已有家庭成员签证状态、具体旅行史组合的信息。
- 页面导航返回 `france.html`，并可直接进入行前规划。

### `france-planning-2026.html`：行前规划

- 从当前综合攻略中提取所有出发前需要决策和预订的内容：
  - 高优预订清单
  - 国际航班选择
  - 法国境内 TGV 与接驳
  - 包车和机场交通
  - 住宿区域与设施筛选
  - 门票价格、开售窗口和预约规则
  - 保险、通信、支付、退税、入境、天气、行李
  - 舒适度与无障碍提示
  - 安全与应急
- 每项需要预约的内容提供：
  - 优先级
  - 建议预订时间
  - 是否强制预约
  - 官方预订链接
  - 价格或价格说明
  - 当前状态勾选框
- 保留本地浏览器中的勾选状态，但使用新的、含义清楚的 localStorage key。
- “老人 + 小孩专项”改名为“舒适度与无障碍提示”。
- 文案改为普适表达：
  - “行动不便或希望减少步行的游客”
  - “儿童游客”
  - “多人同行”
  - “需要连续座位的同行者”
- 删除人数、年龄、家庭关系和“你们家”等表达。
- 总价不再按实际同行人数计算，只展示单价和可填写/心算的公式。

### `france-itinerary-2026.html`：行程安排

- 从当前综合攻略中提取逐日行程。
- 每一天显示：
  - 日期与星期
  - 城市或区域
  - 时段
  - 景点与活动
  - 交通提醒
  - 当日预约提醒
- 每个地点名称旁显示一个明确的地图定位图标 `📍`。
- 点击地点通过 Google Maps Search URL 打开：
  - `https://www.google.com/maps/search/?api=1&query=...`
- 保留日期与营业日、闭馆日、特别活动的匹配结果。
- 把针对具体同行人的建议改成通用提示，例如：
  - “想减少步行可乘小火车”
  - “儿童游客可能更喜欢……”
  - “行动不便者不建议登顶”
- 页面顶部提供到“行前规划”的快捷入口，便于发现需要预约的项目。

## 页面导航

主路径：

`portal.html` → `travel.html` → `france.html` → 三个内容页面

三个内容页面顶部均提供：

- 返回法国
- 上一个/下一个内容页

旧 URL 兼容：

- `france-schengen-2026.html` 保留轻量跳转页，跳转到 `france-visa-2026.html`。
- `france-trip-2026.html` 保留轻量导航页，提示内容已拆分，并提供“行前规划 / 行程安排”两个入口。

这样既不打断旧书签，也避免维护两份重复内容。

## 隐私范围

### 当前部署页面

必须清除：

- 实际人数。
- 实际年龄或年级。
- “太太、父母、父亲、母亲、孩子”等实际同行关系。
- 某个同行者已有签证、具体旅行史或承担全体费用等可组合识别信息。
- 按实际同行构成计算出的门票和交通总价。

可以保留：

- 对不同申请身份的匿名材料清单。
- 儿童票价和儿童免票规则。
- 无障碍、电梯、坡度、步行强度等通用提示。
- 针对长途飞行、慢性病用药等普适安全建议。

### 调研文档

`docs/` 下四份调研底稿也位于公开仓库中，因此同步清理开头和建议段落中的实际同行构成。保留事实、来源和通用判断，删除专门按实际人数计算的总价。

### Git 历史

本次只修改当前版本。过去提交、已合并 PR 和 Git 历史中的旧文本仍然存在。完全删除历史记录需要改写 Git 历史和强制推送，风险高且不在本次范围内。

## 视觉与交互

- 延续现有 Tea X 卡片、主题色和明暗模式。
- 旅行首页的大洲 Tag 复用现有分类筛选按钮视觉。
- 法国首页三个入口使用同等视觉权重，不把其中一个藏在页脚。
- 地图链接用 `📍` 明确表达，而不是仅靠文字下划线或末尾箭头。
- 手机端每行一张卡；桌面端自动多列。
- 筛选和地图跳转仅用原生 JavaScript，不新增依赖。

## 验证

- HTML 结构解析无未闭合标签。
- JavaScript 语法检查通过。
- 大洲 Tag 可正确筛选法国，空分类显示空状态。
- 所有国家页和三个内容页返回 HTTP 200。
- 旧 URL 能到达新结构。
- 每个行程地点都有 `data-q` 和可用的 Google Maps URL。
- localStorage 勾选状态刷新后保留。
- 通过关键词扫描确认当前 HTML 和公开调研文档中不再出现实际同行信息。
- 测试明暗主题和窄屏布局。

## 不做的内容

- 不引入数据库、构建工具或前端框架。
- 不做账号、云端同步或多人协作。
- 不改写 Git 历史。
- 不添加法国以外的虚构国家内容。
